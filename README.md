### ✨ Introduce
---

안녕하세요!
2년차 프론트엔드 개발자 김성현입니다.<br/>

내가 짠 코드는 잘 이해하고 싶어서 모르는 걸 꾸준히 배우고 있습니다.<br/>
특히 웹 성능과 DX에 관심이 많습니다. 

그동안은 Lighthouse를 직접 돌리고 이미지 같은 리소스를 직접 최적화하는 반복 작업을 많이 했는데,<br/> 
브라우저 표준 API로 성능 데이터를 얻을 수 있다는 걸 알게 됐습니다.

최근에는  MDN Performance API 문서를 번역하면서<br/>
CI와 자동화를 통해 손쉽게 성능을 개선하며 좋은 웹을 만들 수 있는 방법을 찾아가고 있습니다.
